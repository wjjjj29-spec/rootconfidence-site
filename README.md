- 식물·의미·기록 카드 내용은 `index.html` 맨 아래 `<script>`의 `plants` / `meanings` / `journal` 배열
- 스토어 링크에는 `utm_source=site`가 붙어 있음 → 스마트스토어센터 유입경로에서 구분
- 이미지 원본은 상세페이지 소스(`../.scratch/content/pN/plate*.png`), 여기 있는 건 900px JPEG
